# Number Guessing Game

A simple Python number guessing game where the player tries to guess a random number within a limited number of attempts.

## Features

- Random number generation
- Difficulty-based guessing range
- Attempt counter
- Replay support
- Simple command-line interface

## How to Play

1. Run the game:
   ```bash
   python main.py
   ```
2. Enter a number between the allowed range.
3. Follow the hints:
   - Too low
   - Too high
   - Correct guess
4. Keep guessing until you win or run out of attempts.

## Example

```text
Welcome to the Number Guessing Game!
I am thinking of a number between 1 and 100.
You have 10 attempts remaining.
Enter your guess: 50
Too low!
```
